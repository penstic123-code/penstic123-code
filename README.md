## Projects

- **[Threedog.js](https://github.com/penstic123-code/Threedog.js-Game-Engine)**: lets an AI build games in plain JavaScript and three.js. The engine handles time, input, assets, saves, physics and world management, and ships tools to run, check and debug a project. Install it from npm: [`threedog`](https://www.npmjs.com/package/threedog).

```bash
npm install threedog@1 three@~0.187.0
```
